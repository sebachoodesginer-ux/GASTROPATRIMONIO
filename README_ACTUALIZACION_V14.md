# GastroPatrimonio — Actualización V14

Esta versión se construye sobre la V13 y aplica los últimos ajustes solicitados:

- Home: entradas independientes en hero, pilares, propósito, accesos rápidos, equipo, publicaciones, banner final y elementos del footer. Cada objetivo se asigna a una dirección de entrada distinta, con velocidades y retrasos escalonados.
- Sub-líneas de investigación: entradas independientes para el título del banner, subtítulo, elementos de introducción, valores, imágenes, números, títulos y descripciones de las cuatro sub-líneas.
- Línea de investigación: frase del banner final centrada vertical y horizontalmente, con tipografía más grande y ajuste responsive.
- Accesibilidad: con `prefers-reduced-motion`, los elementos quedan visibles sin transiciones.

## Cómo probar

1. Descomprimir el ZIP completo.
2. Abrir la carpeta `GASTROPATRIMONIO` en Visual Studio Code.
3. Ejecutar `index.html` con Live Server.
4. Revisar Home, Sub-líneas de investigación y el banner final de Línea de investigación tanto en escritorio como en móvil.

Se debe conservar la estructura de carpetas para que funcionen las rutas locales de CSS, JavaScript e imágenes.
