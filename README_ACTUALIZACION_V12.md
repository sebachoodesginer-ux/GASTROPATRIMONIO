# GastroPatrimonio V12

## Ajustes incluidos

- La página **Línea de investigación** cuenta con animaciones de entrada independientes para títulos, párrafos, iconos, imágenes, tarjetas, llamadas a la acción, elementos del banner final y bloques del pie de página.
- Los elementos se revelan al entrar en el área visible y permanecen visibles después de aparecer.
- Las transiciones usan desplazamientos cortos, duraciones con pequeñas variaciones y una curva suave para evitar entradas bruscas.
- Se aumentó ligeramente el tamaño de textos en el banner, secciones explicativas, tarjetas, metodología, proyección y sub-líneas, con ajustes para pantallas pequeñas.
- El banner final muestra la frase **“Investigar la gastronomía es preservar la memoria de los territorios.”** sobre la fotografía panorámica existente. El texto vive en HTML para mejorar nitidez, adaptación responsive y accesibilidad.
- La animación del contenido principal de esta página se gestiona de forma local para evitar que el sistema global duplique las entradas.
- Se respeta `prefers-reduced-motion` para accesibilidad.

## Uso

Abrir `index.html` con Live Server desde la carpeta `GASTROPATRIMONIO`. Al publicar, mantener la estructura de carpetas y los archivos de `assets`, `css` y `js`.
