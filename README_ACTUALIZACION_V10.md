# GastroPatrimonio — V10

## Cambios incluidos
- Carruseles centrados con avance automático cada 5 segundos, incluso cuando el puntero permanece sobre ellos o el control recibe foco.
- El autoplay se pausa solamente cuando la página está oculta, el carrusel queda fuera de la vista o el usuario ha solicitado reducir el movimiento.
- La página Línea de investigación revela sus elementos una sola vez al entrar en el viewport; los elementos permanecen visibles después para evitar bloques vacíos al llegar al footer.
- El banner inferior conserva su altura natural y no queda oculto por la animación de revelar, eliminando el gran espacio blanco antes del pie de página.
- Entrada del banner superior y aparición al desplazarse ajustadas a una transición más suave.
- Se incorpora `css/v10-refinements.css` después de la capa V9.

## Ejecutar
Abre `index.html` con Live Server y conserva la estructura de carpetas. Los recursos se cargan mediante rutas relativas.
