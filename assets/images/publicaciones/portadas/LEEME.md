# Portadas de publicaciones GastroPatrimonio

Cada archivo tiene un nombre descriptivo y se usa directamente desde las tarjetas de `publicaciones.html` y desde la sección destacada del `index.html`.

Para sustituir una portada, coloca la versión definitiva manteniendo exactamente el nombre del archivo. Si reemplazas con PNG/JPG, conviértela a WebP y conserva el nombre/extensión referenciado por el HTML para no cambiar las rutas.

Los ocho WebP incluidos son recortes ampliados a partir de una captura del explorador de archivos; sirven como recursos de referencia, no como originales editoriales en resolución completa.
