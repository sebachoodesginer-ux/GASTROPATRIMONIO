# GastroPatrimonio — V9

## Cambios de esta versión
- Carrusel de publicaciones destacadas con avance automático cada 5 segundos.
- Contador del carrusel corregido para reflejar el total real de elementos.
- Diseño de carrusel más editorial: publicación activa centrada, mayor escala, halo naranja sutil y transiciones más suaves.
- Logo del footer ampliado y centrado verticalmente en su columna.
- Banner de Línea de investigación más alto y mejor equilibrado.
- Título del banner organizado en dos líneas: “LÍNEA DE” e “INVESTIGACIÓN”, con tamaño responsive para conservar el texto en el área clara de la imagen.
- Entradas más suaves para el banner y las tarjetas de la página de Línea de investigación.
- Se respetan las preferencias de movimiento reducido del sistema.

## Uso
1. Descomprime el ZIP.
2. Abre la carpeta `GASTROPATRIMONIO` en Visual Studio Code.
3. Ejecuta `index.html` con Live Server.
4. Conserva la estructura de carpetas para mantener rutas de imágenes, CSS y JavaScript.
