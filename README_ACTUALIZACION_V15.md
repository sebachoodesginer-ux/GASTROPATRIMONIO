# GastroPatrimonio V15

Esta versión conserva el proyecto V14 y aplica ajustes exclusivos a `opciones-de-grado.html` mediante `css/opciones-grado-v15.css`.

- Se mantienen sin cambios los tres perfiles de la sección Nuestro equipo del Home.
- La página Opciones de grado gana ancho útil, jerarquía tipográfica más clara, tarjetas con imágenes y mejor adaptación responsive.
- La sección de preinscripción se convierte en una franja horizontal de borde a borde, más compacta, conservando el texto y el enlace del formulario.
- Las reglas nuevas se cargan únicamente en la página de Opciones de grado; no se modifican estilos ni scripts globales.

Para probarla, abre `index.html` con Live Server en la carpeta `GASTROPATRIMONIO`.
