# GastroPatrimonio — Actualización V16

Cambios integrados sobre la versión V15:

- Se normalizó la navegación de las siete páginas HTML a los mismos seis destinos y al mismo orden que el Home.
- Se reforzó la visibilidad del equipo en Home y se corrigió el caso de animación de recorte que podía dejar oculto el perfil central de Alejandra María Rodríguez Guarín.
- La descripción del perfil emergente ahora usa fondo blanco, borde naranja y texto de alto contraste.
- Se corrigió el título de la página Sub-líneas para que «DE INVESTIGACIÓN» pueda ajustarse al ancho disponible, sin recortarse.
- Se eliminó la tarjeta rectangular opaca del banner de Opciones de grado; la legibilidad se resuelve mediante un degradado crema a la izquierda.
- Las animaciones de entrada se extienden a las páginas internas con direcciones variadas, observación de scroll más tolerante y un resguardo específico para las tarjetas del equipo en Home.
- Se normalizó el cursor y se impidió que las partículas decorativas intercepten los eventos del puntero.

Para probar: abrir `index.html` desde Live Server conservando la estructura completa de la carpeta.
